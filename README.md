# 🤖 Resume AI

### AI-Powered • Resume Analysis • Job Description Matching • Generative AI

Resume AI is an AI-powered resume analysis and job-matching application built using Dify. It analyzes a user's resume against a Job Description (JD), identifies matching skills and projects, and generates an intelligent analysis using Generative AI.

## 📌 Overview

Resume AI helps students and job seekers understand how well their resume matches a particular job description.

The application takes:

- 📄 Resume
- 💼 Job Description (JD)

The resume is processed using a Document Extractor, and the extracted resume content is combined with the job description and passed to an LLM. The LLM generates an AI-powered analysis highlighting relevant skills, projects, and overall suitability.

## 🔄 How It Works

1. The user opens the Resume AI application.
2. The user uploads their resume.
3. The user provides a Job Description.
4. The resume is passed through the Document Extractor.
5. The extracted resume content is obtained.
6. Resume content and Job Description are provided to the LLM.
7. The LLM analyzes the resume against the JD.
8. The system identifies matching skills and relevant projects.
9. The system generates an AI-powered analysis.
10. The final result is displayed to the user.

---

## 🧠 Prompt Engineering

Prompt Engineering is an important part of Resume AI.

The LLM is instructed to:

- Analyze the provided resume.
- Understand the Job Description.
- Compare required skills with resume skills.
- Identify matching technologies.
- Identify relevant projects.
- Determine overall relevance.
- Provide a clear and structured response.
- Avoid unnecessary information.

The prompt is designed to make the AI act as an intelligent resume and job-matching assistant.

---

## 📝 Example Prompt Structure

You are an AI Resume Analysis Assistant.

Analyze the given resume and compare it with the provided Job Description.

Identify:

1. Matching technical skills
2. Relevant projects
3. Relevant experience
4. Missing or required skills
5. Overall resume relevance

Provide the analysis in a clear and structured format.

Resume:  
{resume_content}

Job Description:  
{job_description}
